# 进程启动器 (Service Launcher)

Windows 上的多服务管理面板：把散落在一堆 `.bat` 和你终端里的后台服务收进一个界面，
一键启停、看得见状态、崩了自动拉起，还能把任意一个注册成**真正的 Windows 服务**
（开机自启、无需登录、无需保持启动器运行）。

中文界面，针对「一台机器上同时跑好几个 Python / Node 服务」这种场景做的。

## 功能

**服务管理**
- 卡片视图 + 总览视图（总览含 CPU / 内存 / 内存曲线，可切 1 小时 / 1 天 / 7 天）
- 分组管理，支持拖拽排序；分组可一键启动（等前一个就绪再启下一个）
- 三种识别方式，任选其一：
  - 按**端口监听** —— 手工启动的同一个服务也能认出来
  - 按**命令行关键字** —— 适合没有端口的机器人
  - 按 **Windows 服务状态** —— 交给系统服务托管的那种

**可靠性**
- **就绪探测**：配置 `healthUrl`，HTTP 2xx/3xx（或 401/403）才算真起来，
  端口开了但接口没就绪不会误报「运行中」
- **崩溃自动重启**：非正常退出才触发，10s → 30s → 60s 退避，可设次数上限
- **每日定时重启**：给内存会缓慢增长的服务设个时间点
- **启动前预检**：工作目录、解释器、Python 依赖、`node_modules`、端口是否被别的程序占用，
  缺什么直接列在卡片上，不用去猜运行时的报错

**Windows 服务托管（内置 WinSW）**
- 卡片上一个按钮：注册 / 取消 Windows 服务托管
- 注册后开机自启、无需登录、崩溃由系统自动重启，**关掉启动器也照跑**

**可观测 / 可维护**
- 实时日志 + 落盘（按天分文件、保留 N 天）、全局日志时间线、导出
- 长期资源曲线（每分钟采样，落盘保留 7 天）
- 环境体检（不启动任何东西，把所有服务的依赖和端口状况查一遍）
- 路径体检 + 批量替换路径前缀（换机器 / 改目录名时一次修好）
- 配置备份 / 恢复、诊断包导出（配置 + 状态 + 日志 + 端口）

**其它**
- 常驻托盘、单实例、窗口位置记忆、环境体检、快捷键、统一字号

## 快速开始

```bash
npm install
npm start                  # 开发模式跑起来
npm test                   # 单元测试（node --test，无需框架依赖）
npm run package:portable   # 打便携版单目录 exe（离线可用）
```

> `npm run package`（electron-forge 官方打包）在 Node 26 上会因为依赖的
> `extract-zip` promise 不返回而静默卡住，所以本项目自带
> `scripts/package-portable.mjs`：它复用已解压的 Electron 运行时 + `@electron/asar`
> 直接组装，离线也能出包。

## 配置文件放哪

运行时数据都在用户目录，**不会进仓库**：

| 内容 | 位置 |
|---|---|
| 服务配置 | `%APPDATA%\进程启动器\config.json` |
| 配置备份 | `%APPDATA%\进程启动器\backups\` |
| 落盘日志 | `%APPDATA%\进程启动器\logs\` |
| 资源曲线 | `%APPDATA%\进程启动器\metrics\` |
| 服务包装文件 | `C:\ProgramData\ProcessLauncher\services\` |

配置可以在界面里导出 / 导入，格式是普通的 JSON（`{ apps, groups, version }`）。

## 技术栈

Electron 40 + React 19 + TypeScript + Vite + Tailwind CSS。
系统探测走 `netstat` / `sc` / CIM，**没有原生模块**，所以打包和跨机器部署都很轻。
